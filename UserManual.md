# Pressure/RTD control

1) Specify processed ports in MainConfig file "currently_processed_temperature_ports","currently_processed_voltage_ports" entries as lists of the following format: [x,y,z]
2) Enter calibration polynomes for pressure transducers (calibration procedure not specified yet)

3) Run "python3 main.py" command to start logging temperature and pressure

4) Run "python3 PressureScreen.py" and "python3 TemperatureScreen.py" commands to display live plots of pressure and temperature
